# Backend — QR Empresarial

API REST en Node.js 22 + Express 5 con MySQL.

Se construye a partir del sprint 0 siguiendo la estructura definida en el plan de desarrollo:
`src/config`, `src/models`, `src/repositories`, `src/services`, `src/controllers`,
`src/routes`, `src/middlewares`, `src/validators` y `src/utils`.
